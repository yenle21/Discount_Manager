Discount Manager

Giới thiệu

## 🛠️ Công nghệ sử dụng
- **Backend:** Python, Flask
- **Database:** SQLite, MySQL
- **Frontend:** HTML, CSS, Bootstrap
- **Testing:** Pytest, Selenium, Postman

## ⚙️ Cài đặt và chạy project

### 1. Clone project
git clone <link_repo>

### 2. Cài đặt thư viện
pip install -r requirements.txt

### 3. Chạy ứng dụng
python models.py
python index.py
